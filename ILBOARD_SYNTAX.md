## Первая программа

```python
from ilboard import Board, sleep

main = Board("main", size=10)
main.text("А", "#2563eb")
sleep(1)
main.number(7, "#22c55e")
```

Пишем обычный Python. Связь с виртуальными устройствами даёт библиотека `ilboard`. Устанавливать её через `pip` не нужно: она уже встроена в сайт. В обычном системном Python этот модуль не существует.

## Импорт

Библиотека экспортирует ровно три публичных имени: `Board`, `sleep`, `wait`.

```python
from ilboard import Board, sleep, wait

main = Board("main")
sleep(0.5)
wait(0.5)
```

`wait` — другое имя той же функции паузы. Обычно достаточно `sleep`.

Допустимы псевдонимы пауз и импорт модуля:

```python
import ilboard
from ilboard import sleep as pause

main = ilboard.Board("main")
main.fill("blue")
pause(1)
ilboard.sleep(1)
```

Для примеров ниже подразумевается импорт `Board` и `sleep`, если они используются. Лучше не переименовывать `Board` в учебных программах: интерфейс автоматически обновляет простые вызовы `Board("имя", size=10)` при переименовании и изменении размера платы.

## Создание и выбор платы

```python
main = Board(name="main", size=10)
```

| Параметр | Значение |
| --- | --- |
| `name` | Имя платы; по умолчанию `"main"`. От 1 до 24 символов после удаления пробелов по краям. |
| `size` | Целое число от 5 до 20 включительно. Создаёт квадратную матрицу `size × size`. |

```python
main = Board()                  # плата main; новая плата — 10×10
main = Board("main")            # существующая main сохраняет размер
screen = Board("вывеска", 15)    # создать/выбрать вывеску и задать 15×15
same = Board("вывеска")          # та же самая плата
```

Если имя существует, возвращается объект, управляющий этой платой. Если имени нет, создаётся новая плата. В проекте максимум четыре платы. Указанный `size` меняет размер существующей платы, если он отличается; при изменении размера изображение очищается.

Имя Python-переменной и имя платы независимы:

```python
left = Board("левая")
right = Board("правая")
left.text("Л")
right.text("П")
```

`left` и `right` — переменные в коде. `"левая"` и `"правая"` — названия вкладок интерфейса. Переименование переменной само по себе не переименовывает плату.

### Свойства

```python
main = Board("main", size=10)
print(main.name)     # main
print(main.size)     # 10
print(main.width)    # 10
print(main.height)   # 10
```

Используйте эти свойства для чтения. Имя меняйте через интерфейс, размер — через `resize` или аргумент `size`. Присваивание `main.size = 20` не поддерживается.

## Все команды платы

`color=None` в сигнатуре означает: взять текущий цвет, установленный через `main.color(...)`. Начальный цвет при запуске — `#2563eb`.

| Сигнатура | Результат и действие |
| --- | --- |
| `main.resize(size)` | Изменить размер и очистить матрицу; 5–20. Даже при том же размере явный вызов очищает изображение. |
| `main.pixel(x, y, color=None)` | Установить цвет одного светодиода. |
| `main.set_pixel(x, y, color=None)` | Полный синоним `pixel`. |
| `main.get_pixel(x, y)` | Вернуть установленный цвет или `None`, если светодиод выключен. |
| `main.color(color)` | Изменить цвет следующих команд без явного аргумента `color`. |
| `main.fill(color=None)` | Включить всю матрицу выбранным цветом. |
| `main.clear()` | Выключить всю матрицу. |
| `main.brightness(value)` | Общая яркость платы от 0 до 100; выходящие значения ограничиваются этим диапазоном. |
| `main.text(value, color=None)` | Показать текст по центру, заменив предыдущее изображение. |
| `main.number(value, color=None)` | Полный синоним `text`; удобен для чисел. |
| `main.scroll(value, color=None, speed=0.09)` | Прокрутить текст; `speed` — секунды между кадрами. |
| `main.show(rows, color=None)` | Показать рисунок из строк или списка строк. |
| `main.button(key)` | Вернуть `True`/`False` для кнопки `"A"` или `"B"`. |
| `main.light()` | Вернуть освещённость: число 0–100. |
| `main.temperature()` | Вернуть температуру: число −20…60 °C. |
| `main.distance()` | Вернуть расстояние: число 0–200 см. |

Команды рисования, настройки и изменения размера возвращают `None`. Возвращаемые значения есть у `get_pixel`, `button` и трёх методов датчиков. Например, `print(main.fill("red"))` выведет `None`; это не ошибка рисования.

`clear()` не сбрасывает выбранный цвет и яркость. Нулевая яркость скрывает свет, но не стирает содержимое матрицы. Верните `brightness(100)`, чтобы увидеть его снова.

## Цвета

```python
main = Board("main")
main.fill("red")                     # CSS-имя
main.fill("#ff8800")                 # HEX, 6 цифр
main.fill("#f80")                    # HEX, 3 цифры
main.fill("rgb(255, 136, 0)")         # CSS-строка
main.fill("hsl(210, 100%, 50%)")       # CSS-строка
main.fill((255, 136, 0))              # RGB-кортеж
main.fill([255, 136, 0])              # RGB-список
```

У RGB три компонента; значения приводятся к целым и ограничиваются 0–255. Цветовые имена и CSS-строки распознаёт браузер. Нераспознанная цветовая строка в текущей версии отображается стандартным синим, а не вызывает ошибку. Используйте проверенные CSS-цвета или палитру.

```python
main.color("#8b5cf6")
main.pixel(0, 0)                     # фиолетовый
main.text("А")                      # фиолетовый
main.text("Б", "#22c55e")            # зелёный только для этой команды
main.text("В")                      # снова фиолетовый
```

Чтобы выключить один светодиод, передайте `False` или `0`:

```python
main.pixel(0, 0, False)
main.set_pixel(1, 0, 0)
```

`None` в аргументе цвета не выключает светодиод: он выбирает текущий цвет. Для выключения всей матрицы используйте `clear()`.

Палитра редактора вставляет обычную строку `"#2563eb"` в позицию курсора или заменяет выделение. Цветная полоска под CSS-цветом позволяет изменить только содержимое строки. Изменение кода вступает в силу при следующем запуске программы.

## Пиксели и рисунки

Координаты — целые числа. `(0, 0)` находится в левом верхнем углу. `x` растёт вправо, `y` — вниз. Для размера 10 допустимы значения от 0 до 9.

```python
main = Board("main", size=10)
main.clear()
main.pixel(0, 0, "red")
main.pixel(main.width - 1, main.height - 1, "blue")
print(main.get_pixel(0, 0))           # red
```

### Линия, квадрат, диагональ

```python
main.clear()
for x in range(main.width):
    main.pixel(x, 0, "#2563eb")

for y in range(2, 5):
    for x in range(2, 5):
        main.pixel(x, y, "#22c55e")

for i in range(main.size):
    main.pixel(i, i, "#f97316")
```

### Готовый рисунок

```python
heart = [
    "01010",
    "11111",
    "11111",
    "01110",
    "00100",
]
main.show(heart, "#ef4444")
```

Рисунок центрируется, остальные светодиоды выключаются. Число строк и длина каждой строки не должны превышать размер матрицы. Для пустых клеток подходят `0`, точка и пробел; для включённых удобнее использовать `1`. Можно передать многострочную строку:

```python
main.show("010\n111\n010", "#2563eb")
```

## Буквы, числа и бегущая строка

```python
main = Board("main", size=10)
main.text("А")
main.text("Z", "#f97316")
main.number(42, "#22c55e")
main.text("♥", "#ef4444")
main.text(123)                       # число тоже преобразуется в текст
```

Поддерживаются русский алфавит, включая Ё, английский алфавит, цифры 0–9 и символы: пробел, `!`, `?`, `.`, `-`, `+`, `:`, `♥`, `❤`. Буквы переводятся в верхний регистр. Остальные символы заменяются знаком вопроса. Рисунок адаптируется к матрице; длинное сообщение при сжатии станет неразборчивым.

```python
main.scroll("ПРИВЕТ ILBOARD!", "#2563eb", speed=0.08)
```

`scroll` выполняет всю прокрутку, затем код продолжается. Последний кадр очищает матрицу. Чтобы повторять сообщение:

```python
while True:
    main.scroll("ОТКРЫТО", speed=0.1)
    sleep(0.5)
```

## Кнопки

```python
main = Board("main")
while True:
    if main.button("A"):
        main.text("А", "#2563eb")
    elif main.button("B"):
        main.text("Б", "#ef4444")
    else:
        main.clear()
    sleep(0.03)
```

Ключи кнопок — латинские `A` и `B`; регистр не важен. Кириллическая `А` в имени кнопки не подходит. Каждая плата имеет свои кнопки. При удержании результат остаётся `True`; после короткого клика симулятор оставляет краткий импульс, чтобы программа успела заметить нажатие.

Чтобы считать один раз на нажатие, храните предыдущее состояние:

```python
count = 0
was_pressed = False

while True:
    pressed = main.button("A")
    if pressed and not was_pressed:
        count += 1
    was_pressed = pressed
    main.number(count)
    sleep(0.03)
```

## Датчики

Все три датчика независимы для каждой платы. Ползунки меняют входные значения во время работы программы. Возвращаемый тип — `float`; для вывода целого числа используйте `round` или `int`.

```python
print(main.light())                  # например, 70.0
print(main.temperature())            # например, 22.0
print(main.distance())               # например, 50.0
```

### Ночник

```python
while True:
    if main.light() < 30:
        main.fill("#fbbf24")
    else:
        main.clear()
    sleep(0.1)
```

### Термометр с тревогой

```python
while True:
    temperature = main.temperature()
    color = "#ef4444" if temperature > 30 else "#2563eb"
    main.number(round(temperature), color)
    sleep(0.1)
```

### Сигнал близости

```python
while True:
    if main.distance() < 25:
        main.text("!", "red")
    else:
        main.text("О", "green")
    sleep(0.1)
```

## Паузы

```python
sleep(1)                            # 1 секунда
sleep(0.05)                         # 50 миллисекунд
wait(0.5)                           # нужен импорт wait
```

Минимальная фактическая пауза в реализации — 0.001 секунды. Отрицательный аргумент также превращается в минимальную паузу; не используйте отрицательные значения для описания алгоритма. Внутренние задержки браузера могут увеличить время.

Циклы автоматически уступают управление интерфейсу. Пауза всё равно нужна для понятной скорости анимации и частоты проверки датчиков. Можно использовать `time.sleep`, но для учебных программ рекомендуется `ilboard.sleep`.

## Четыре платы

```python
from ilboard import Board, sleep

boards = [
    Board("main", size=10),
    Board("board2", size=10),
    Board("board3", size=15),
    Board("display", size=20),
]
colors = ["#2563eb", "#8b5cf6", "#ef4444", "#22c55e"]

for number, board in enumerate(boards):
    board.number(number + 1, colors[number])
```

Программа выполняется последовательно. Если сначала вызвать долгий `boards[0].scroll(...)`, следующая команда для другой платы выполнится после прокрутки. Для одновременного по смыслу обновления нескольких плат используйте общий цикл с короткими операциями рисования:

```python
while True:
    for board in boards:
        board.number(round(board.temperature()))
    sleep(0.1)
```

Переключение вкладок выбирает отображаемую плату и её ползунки, но не ограничивает выполнение кода этой платой. Значок сетки показывает все платы сразу.

## Синтаксис Python

Это справочник конструкций, полезных для работы в ilboard, а не описание всей грамматики языка Python. Базовые конструкции выполняются настоящим Python; особая адаптация требуется только паузам и кооперативным циклам.

### Комментарии, отступы и строки

```python
# Комментарий не выполняется.
color = "#2563eb"                    # это строка, а не комментарий
text = 'Привет'
message = "Первая строка\nВторая"

if True:
    print("Внутри условия")          # четыре пробела
print("После условия")
```

После заголовков `if`, `elif`, `else`, `for`, `while`, `def`, `try`, `except`, `finally` ставится `:`. Вложенный блок имеет одинаковые отступы. Имена чувствительны к регистру: `main` и `Main` — разные переменные.

### Типы и переменные

```python
count = 3                           # int
delay = 0.25                        # float
title = "СЧЁТ"                      # str
enabled = True                      # bool: True или False
empty = None                        # отсутствие значения
coordinates = (2, 3)                 # tuple
colors = ["red", "blue"]             # list
settings = {"limit": 30}             # dict
used = {1, 2, 3}                     # set

count += 1
print(type(count))
print(str(count), int("12"), float("1.5"), bool(1))
```

### Операторы

| Операторы | Значение | Пример |
| --- | --- | --- |
| `+`, `-`, `*`, `/` | Сложение, вычитание, умножение, деление | `5 / 2 == 2.5` |
| `//`, `%`, `**` | Целая часть деления, остаток, степень | `5 // 2 == 2`, `5 % 2 == 1`, `2 ** 3 == 8` |
| `=`, `+=`, `-=`, `*=`, `/=` | Присваивание и изменение | `count += 1` |
| `==`, `!=`, `<`, `<=`, `>`, `>=` | Сравнения | `temperature >= 30` |
| `and`, `or`, `not` | Логические операции | `a and not b` |
| `in`, `not in` | Проверка вхождения | `color in colors` |
| `is`, `is not` | Проверка идентичности; полезна для None | `value is None` |

Для сравнения значений используйте `==`, а не `=` или `is`.

### Условия

temperature = 25
if temperature > 30:

elif temperature < 10:
    color = "blue"
else:

color = "red" if temperature > 30 else "green"

### Цикл for и range

```python
for i in range(5):                   # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 6):                # 2, 3, 4, 5
    print(i)

for i in range(9, -1, -1):           # 9 ... 0
    print(i)

for color in ["red", "blue"]:
    main.fill(color)
    sleep(0.5)
```

Правая граница `range` не включается.

### Цикл while, break, continue

```python
count = 0
while count < 10:
    count += 1
    if count == 3:
        continue                    # перейти к следующему повтору
    if count == 8:
        break                       # выйти из цикла
    main.number(count)
    sleep(0.2)
```

`while True` работает до `break`, ошибки или нажатия «Стоп».

### Функции

```python
def choose_color(temperature, limit=30):
    if temperature > limit:
        return "red"
    return "blue"

def blink(board, color, times=3):
    for i in range(times):
        board.fill(color)
        sleep(0.2)
        board.clear()
        sleep(0.2)

blink(main, choose_color(main.temperature()))
```

Функция без `return` возвращает `None`. Обычные функции без пауз можно использовать в `map`, `sorted(key=...)` и других стандартных операциях. Функции с циклами или паузами адаптируются симулятором; для них предпочтительны прямые вызовы, как в примере выше, а не передача в сторонние синхронные функции.

### Полезные встроенные функции

```python
print("Счёт:", 7)                    # вывод в консоль
print(len([1, 2, 3]))
print(round(22.7), abs(-5))
print(min(2, 7), max(2, 7))
print(sum([1, 2, 3]))
print(sorted([3, 1, 2]))
print(list(reversed([1, 2, 3])))
print(all([True, True]), any([False, True]))
```

`input()` не служит вводом с клавиатуры в этом интерфейсе. Для интерактивного управления используйте кнопки и датчики.

### Исключения

```python
try:
    main.pixel(999, 0, "red")
except ValueError as error:
    print("Ошибка координат:", error)
finally:
    print("Проверка закончена")
```

Собственная проверка:

```python
def check_size(size):
    if size < 5 or size > 20:
        raise ValueError("Размер должен быть от 5 до 20")
    return size

assert check_size(10) == 10
```

Кнопка «Стоп» завершает весь Worker. Она не является обычным исключением Python; выполнение `finally` при такой остановке не гарантируется.

Часть стандартной библиотеки в браузере имеет ограничения. Обычные математические операции, коллекции и случайные числа — подходящие темы для курса. Системные процессы, доступ к произвольным файлам компьютера и сетевое взаимодействие не относятся к поддерживаемому интерфейсу ilboard. Архив содержит необходимые файлы движка и стандартной библиотеки, но не все сторонние пакеты Python.

## Ошибки и ограничения

| Сообщение / ситуация | Причина и действие |
| --- | --- |
| `SyntaxError` | Проверьте двоеточия, скобки, кавычки и запись команды. |
| `IndentationError` | Проверьте одинаковые отступы внутри блока. |
| `NameError` | Переменная не создана, опечатка или забытый импорт. |
| `TypeError` | Неподходящий тип аргумента, например дробная координата. |
| `ValueError` о координатах | Светодиод за пределами матрицы; координаты начинаются с 0. |
| `ValueError` о размерах | Используйте целый размер 5–20. |
| `ValueError` о количестве плат | В проекте уже четыре платы; повторно используйте их имена. |
| `ValueError` о рисунке | Рисунок больше выбранной матрицы. |
| Ничего не светится | Проверьте `brightness`, выбранную вкладку и наличие команды рисования. |
| Программа закончилась, изображение осталось | Это нормально: состояние платы сохраняется до следующей команды. |
| Удалённая плата появилась снова | Код `Board("имя")` создаёт её заново. |

На новом запуске код выполняется с новой областью переменных, но изображение и яркость плат могут сохраниться с предыдущего запуска. Если нужен чистый старт, явно вызовите `clear()` и `brightness(100)`.

Особые ограничения текущего адаптера: сложные `async`-программы, генераторы с паузами, асинхронные методы классов и циклы или паузы внутри `__init__` не входят в гарантированную учебную совместимость. Не требуется писать `await` для `sleep`, `scroll` и учебных функций: преобразование делает симулятор. Для курса используйте простые функции, условия и циклы из этого справочника.

Платы виртуальные. Датчики получают значения ползунков; это не показания реальных датчиков компьютера. Библиотека не управляет физической micro:bit, Arduino или другой платой.

## Формат файла и редактор

- `.ilpy` — обычный UTF-8 текст Python. Специальных заголовков нет.
- «Скачать .ilpy» сохраняет весь код редактора.
- «Импорт» и перетаскивание `.ilpy` в редактор заменяют текущий код. Перед заменой скачайте свою работу.
- Файл не хранит положение ползунков, тему интерфейса и текущий кадр. Имена и размеры плат задавайте в коде через `Board`.
- `Ctrl+Enter` — запуск, «Стоп» или `Shift+Escape` — остановка.
- `Tab` — четыре пробела; Enter после `:` добавляет отступ.
- Клавиши A/B управляют кнопками выбранной платы, если курсор находится вне полей ввода и редактора.
- Кнопка цвета открывает вставку CSS-цвета; полоска под цветовой строкой — редактирование существующего цвета.
- Браузер сохраняет рабочее состояние локально. Для переноса на другой компьютер нужен `.ilpy`.
