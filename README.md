# ilboard

[Полный справочник синтаксиса](ILBOARD_SYNTAX.md) · [Курс на 12 пар](materials/ilboard-guide.md) · [Учебные примеры](materials/examples/)

Браузерная среда Python: до четырёх именованных светодиодных плат, квадратные матрицы от 5×5 до 20×20. Кнопки A/B, датчики света, температуры и расстояния для каждой платы. Светлая и тёмная темы. Без регистрации, города и звуков.

Запуск: `python -m http.server 4173 --directory dist`, затем http://localhost:4173.

GitHub Pages: workflow `.github/workflows/pages.yml` проверяет проект и публикует каталог `dist`. В настройках репозитория нужно включить Pages с источником GitHub Actions; затем запустить workflow вручную либо отправить изменения сайта в `main`. Поддержка Pages для приватного репозитория зависит от тарифа GitHub. Все ресурсы используют относительные пути и работают при размещении в подкаталоге проекта.

Код и конфигурация сохраняются локально в браузере. Импорт и экспорт `.ilpy` — обычный UTF-8 Python без JSON и скрытых заголовков. Для переноса размеров и создания плат код использует `Board("имя", size=10)`; при запуске отсутствующие платы создаются автоматически. Выбор размера и переименование в интерфейсе обновляют простые вызовы `Board` в коде.

Python выполняется в Pyodide 0.27.7 / CPython 3.12.7 в Web Worker. Движок включён в `dist/vendor/pyodide`, шрифты системные: после распаковки сайт работает без интернета через локальный HTTP-сервер. Остановка завершает Worker и запускает новый. Состояния датчиков передаются в Worker, команды плат обратно в интерфейс. AST добавляет кооперативные паузы в циклы и преобразует функции с паузами; обычные функции без пауз работают синхронно. Поддерживаются `ilboard.sleep`, `ilboard.wait`, импортированные с псевдонимом функции и `time.sleep`. Для сложного async Python, классов с асинхронными методами и генераторов совместимость не гарантируется.

Команды: `pixel`, `get_pixel`, `fill`, `clear`, `text`, `number`, `scroll`, `show`, `color`, `brightness`, `button`, `light`, `temperature`, `distance`, `resize`. Алфавиты: русский, английский, цифры и базовые символы. Цвет: CSS-имя, HEX или RGB-кортеж. Координаты от нуля.

Проверка: `python check_python.py`; синтаксис: `node --check dist/app.js` и `node --check dist/python-worker.js`. Проверки используют тот же `runtime.py` и шрифт, которые загружаются в браузере.

Палитра: кнопка цвета в редакторе вставляет HEX в выделение, полоска под цветовой строкой открывает её редактирование. Яркость светодиодов усилена свечением и светлым центром; нулевая яркость гасит свечение.

Учебные материалы: `materials/ilboard-guide.md` и `materials/examples/`. `python build_teaching_kit.py` создаёт `D:/ilboard/ilboard-teaching-kit.zip` с приложением, движком, запуском для Windows и 12 примерами. `prepare_offline.py` используется разработчиком для повторной загрузки закреплённого движка; ученикам он не нужен. Для запуска локального HTTP-сервера требуется установленный Python; его Windows-инсталлятор в архив не входит.
