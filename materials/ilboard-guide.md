# ilboard — справочник и курс на 12 пар

Материалы для учителя и учеников 9–16 лет. План рассчитан на 12 занятий по 90 минут: 18 обычных часов, или 24 академических часа. Это проектный курс начального Python. Темп нужно выбирать по группе: младшим — больше готовых заготовок, старшим — дополнительные задачи и самостоятельная архитектура.

## Что входит в архив

- `app/` — весь сайт, собственная библиотека `ilboard`, шрифт матрицы и локальный Python-движок Pyodide 0.27.7 / Python 3.12.7.
- `examples/` — 12 открываемых программ `.ilpy`, по одной на занятие.
- `START.cmd` — локальный запуск в Windows.
- Этот справочник: запуск, команды, темы занятий, задания и ограничения.
- `app/vendor/pyodide/` — необходимые файлы движка, лицензии и контрольные суммы.

Это полный комплект для работы с текущими возможностями ilboard. Он не содержит все существующие библиотеки Python: NumPy, pandas, pygame и сторонние пакеты для этих занятий не нужны и в архив не включены.

## Запуск без интернета

1. Распакуйте ZIP целиком в отдельную папку.
2. На компьютере нужен установленный Python 3.10 или новее. Установка Python в архив не входит. Для выполнения ученического кода используется встроенный браузерный Python; установленный Python только запускает локальный веб-сервер.
3. Запустите `START.cmd`, оставьте окно сервера открытым.
4. Откройте `http://127.0.0.1:4173/` в современном Chrome или Edge.
5. Дождитесь «Python готов». Импортируйте `.ilpy` или перетащите его в редактор.

Движок и сайт загружаются с этого компьютера, поэтому интернет не нужен. Не открывайте `index.html` двойным щелчком: Web Worker и WebAssembly требуют HTTP-сервера. Если порт занят другим ilboard, уже открытый сайт продолжает работать; закройте прежний сервер перед запуском новой копии. Остановка окна сервера выключает сайт.

Проекты автоматически сохраняются только в текущем браузере и на текущем адресе. В конце занятия каждый ученик скачивает `.ilpy`. Файл содержит обычный текст Python без скрытого JSON. Размеры и имена плат переносятся через вызовы `Board("имя", size=10)` в коде. Положения ползунков датчиков в `.ilpy` не сохраняются.

## Библиотеки

Главная учебная библиотека одна:

```python
from ilboard import Board, sleep
```

Для более сложных заданий пригодятся стандартные модули:

```python
import random     # случайные числа: randrange, randint, choice
import math       # sin, cos, pi, sqrt
import time       # monotonic для измерения времени
```

`sleep` и `wait` из `ilboard` приостанавливают программу, оставляя кнопки и датчики доступными. Поддерживается и `time.sleep`. Для первых занятий используйте один вариант — `sleep` из `ilboard`. Модули `asyncio`, `json`, `ast`, `sys`, `types` и `math` используются внутри движка; ученикам не нужно их устанавливать или импортировать для управления платой.

## Первые команды

```python
from ilboard import Board, sleep

main = Board("main", size=10)
main.text("А", "#2563eb")
sleep(1)
main.number(7, "#22c55e")
```

Создайте до четырёх плат. Имя объекта Python и имя платы — разные вещи:

```python
left = Board("левая", size=10)
right = Board("правая", size=20)
left.text("Л")
right.text("П", "orange")
```

`left` — переменная Python, `"левая"` — имя платы в интерфейсе. Повторный `Board("левая")` обращается к той же плате. Незнакомое имя создаёт новую плату, если лимит не исчерпан. В этом случае удалённая через интерфейс плата появится снова при запуске соответствующего `Board(...)`.

## Полный справочник ilboard

| Команда | Действие |
| --- | --- |
| `Board("main", size=10)` | Получить или создать плату. Квадратная матрица: целое число 5–20. До 4 плат. |
| `main.name` | Имя платы. |
| `main.size`, `main.width`, `main.height` | Текущий размер; например, 10. |
| `main.resize(15)` | Изменить размер и очистить матрицу. |
| `main.pixel(x, y, color)` | Включить один светодиод. `set_pixel` — другое имя той же команды. |
| `main.get_pixel(x, y)` | Прочитать цвет светодиода или `None`, если он выключен. |
| `main.pixel(x, y, False)` | Выключить конкретный светодиод. Также можно передать `0`. |
| `main.fill(color)` | Залить всю матрицу цветом. |
| `main.clear()` | Выключить все светодиоды. |
| `main.color(color)` | Выбрать цвет для следующих команд без указанного цвета. Уже включённые светодиоды не перекрашиваются. |
| `main.brightness(80)` | Общая яркость платы: 0–100. Не меняет выбранный цвет. |
| `main.text("А", color)` | Показать текст по центру. Русский, английский, цифры, базовые знаки и сердце. Цвет можно опустить. |
| `main.number(42, color)` | То же отображение для числа. |
| `main.scroll("ПРИВЕТ", color, speed=0.09)` | Прокрутить текст. `speed` — пауза между кадрами в секундах; меньше — быстрее. Цвет можно опустить. |
| `main.show(rows, color)` | Показать рисунок из строк. `1` — включить, `0`, точка или пробел — выключить. Рисунок не должен быть больше матрицы. |
| `main.button("A")` | Нажата ли кнопка A: `True` или `False`. Для B — `main.button("B")`. |
| `main.light()` | Освещённость выбранной платы, 0–100. |
| `main.temperature()` | Температура выбранной платы, от −20 до +60 °C. |
| `main.distance()` | Расстояние выбранной платы, 0–200 см. |
| `sleep(1)` / `wait(1)` | Пауза в секундах. `wait` тоже нужно импортировать из `ilboard`. |

Координаты начинаются с нуля: `(0, 0)` — левый верхний угол, `x` растёт вправо, `y` — вниз. На 10×10 допустимы координаты 0–9. Выход за границы вызывает ошибку, а не расширяет плату.

Цвета: `"red"`, `"blue"`, `"#ff8800"`, `"rgb(255, 136, 0)"` или кортеж `(255, 136, 0)`. Палитра в редакторе вставляет HEX-цвет. Цветная полоска под строкой цвета открывает его редактирование. Сохранённый `.ilpy` содержит обычный HEX, без специального синтаксиса. Короткий HEX `#f80` также допустим.

Для маленьких матриц лучше один символ, для длинных сообщений — `scroll`. Длинная строка в `text` будет сжата до размеров матрицы и может стать неразборчивой. Пиксельный шрифт не равнозначен обычному экранному шрифту.

```python
main.show([
    "01010",
    "11111",
    "11111",
    "01110",
    "00100",
], "#ef4444")
```

## Работа в редакторе

- «Запустить» или `Ctrl+Enter` — выполнить код.
- «Стоп» — прервать программу. `Shift+Escape` — та же команда.
- `Tab` — отступ в четыре пробела. Enter после двоеточия добавляет отступ.
- Кнопки A/B можно нажимать мышью или соответствующими клавишами, когда курсор находится вне редактора и полей ввода.
- Ползунки относятся к выбранной плате. Переключение вкладок не останавливает программу.
- Значок сетки показывает все платы одновременно.
- Палитра меняет код; чтобы увидеть новый цвет на плате, запустите программу заново.
- «Скачать .ilpy» сохраняет код. «Импорт» заменяет текущий код; перед импортом чужого примера скачайте свою работу.

## План на 12 пар

Обычная структура пары: 5 минут — цель и проверка прошлого, 15 — разбор с учителем, 20 — совместная практика, 5 — перерыв, 30 — самостоятельное задание, 10 — демонстрации и исправление ошибок, 5 — сохранение файла. Это ориентир, а не обязательный таймер.

| Пара и файл | Python | Обязательный результат | Дополнительное задание |
| --- | --- | --- | --- |
| 1. `01_first_pixels.ilpy` | Команды, строки, координаты | Свой знак из 5–10 светодиодов; объяснить `(0, 0)`. | Нарисовать симметричный знак и перенести его на другой размер. |
| 2. `02_colors_and_variables.ilpy` | Переменные, числа, параметры | Три цвета через переменные; смена яркости. | Задать тему из нескольких RGB-кортежей. |
| 3. `03_animation.ilpy` | Последовательность, `sleep` | Три кадра своей анимации. | Подобрать скорость, добавить паузу и завершающий кадр. |
| 4. `04_loops.ilpy` | `for`, `range`, вложенные циклы | Бегущая точка и заполненная строка. | Заполнение по диагонали или змейкой на любом размере. |
| 5. `05_buttons.ilpy` | `if`, `elif`, `else`, `while`, логические значения | Разные действия кнопок A/B. | Отдельная реакция на одновременное нажатие. |
| 6. `06_sensors.ilpy` | Сравнения, пороги, `and`/`or` | Индикатор температуры или расстояния. | Два порога, три состояния и проверка граничных значений. |
| 7. `07_counter.ilpy` | Состояние, изменение переменных | Счётчик: A прибавляет, B сбрасывает. | Ограничение 0–99 и защита от многократного счёта одного нажатия. |
| 8. `08_functions.ilpy` | `def`, аргументы, повторное использование | Своя функция рисунка, вызванная с разными цветами. | Возвращаемое значение, независимые функции для двух эффектов. |
| 9. `09_lists.ilpy` | Списки, пары координат, обход | Анимация из собственного набора кадров. | Хранить палитры и рисунки отдельно от кода управления. |
| 10. `10_random_game.ilpy` | `random`, правила игры | Игра «найди столбец»: A перемещает курсор, B проверяет. | Счёт очков, уровни сложности, ограничение времени. |
| 11. `11_multiple_boards.ilpy` | Объекты, списки объектов, разделение ролей | Две или четыре платы: показания, тревога, статус. | Каждая плата читает собственный датчик и имеет отдельный порог. |
| 12. `12_final_project.ilpy` | Проектирование, отладка, объяснение | Собственный завершённый проект и короткая защита. | Меню режимов, рекорды в пределах запуска, несколько плат. |

### Как провести каждое занятие

Не начинайте с копирования всего готового файла. Сначала дайте работающие 3–5 строк, попросите предсказать результат, затем изменить один параметр. Пример из архива — опора учителю и стартовая заготовка. После изменения ребёнок должен объяснить, какая строка изменила поведение.

Для 9–11 лет: заготовка с импортом, созданием платы и пустыми местами для двух-трёх команд; учитель показывает координаты на доске. Не вводить несколько новых конструкций одновременно. На парах 8–10 функции и списки можно сначала разбирать на готовых примерах.

Для 12–16 лет: сначала сформулировать алгоритм словами, затем написать код самостоятельно. Требовать понятные имена переменных, функции, обработку границ и проверку разных входных значений. Сильные ученики не просто добавляют больше цветов: они делают код универсальным для любого размера платы.

### Минимум перед переходом к следующей теме

1. Ученик запускает и останавливает программу, скачивает и открывает свой файл.
2. Объясняет порядок команд и разницу между строкой и числом.
3. Предсказывает результат цикла и указывает диапазон координат.
4. Отличает проверку состояния кнопки от однократного события нажатия.
5. Может назвать вход, условие и выход программы с датчиком.
6. Находит ошибку по сообщению в консоли и проверяет исправление.

Если группа не успевает, пары 8–10 можно превратить в развитие одного счётчика или индикатора, а не вводить новые проекты каждый раз. Если идёт быстрее — усложнять правила, проверку и структуру кода. Само наличие матрицы не гарантирует 12 содержательных пар: длительность обеспечивает последовательное изучение Python и самостоятельная работа.

## Итоговый проект

Варианты: погодная станция, игра с двумя кнопками, счётчик посетителей, интерактивная вывеска, мониторинг четырёх помещений. Без звуков и внешних устройств.

Минимальные требования: переменная состояния, цикл, условие, собственная функция, хотя бы один ввод (кнопка или датчик), понятный результат на плате. Ребёнок показывает нормальный сценарий и один крайний случай: нулевая яркость, высокая температура, максимальный счёт или выход за границу.

Оценивание из 10: работоспособность — 4, структура и читаемость кода — 2, объяснение — 2, самостоятельное улучшение и проверка — 2. Не оценивать скорость набора текста или красоту рисунка как знание Python.

## Ограничения текущей версии

До 4 плат, квадратные матрицы 5–20, один экземпляр каждого датчика на плату. Датчики виртуальные: значения задаются ползунками, это не подключение к физическому оборудованию. Базовый Python выполняется в браузере; файловая система компьютера, сеть, сложный async-код, генераторы с паузами и асинхронные методы классов не входят в учебную поддержку. Для таких задач сначала нужна отдельная проверка совместимости.

Встроенный Python и паузы адаптированы для симулятора. Программу с `ilboard` нельзя просто запустить обычным системным Python: там нет браузерных плат и этого модуля.
